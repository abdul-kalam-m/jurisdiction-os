# Jurisdiction Intelligence OS

**"Bloomberg Terminal for local permitting risk"** — a portfolio demonstration of a B2B proptech
product: jurisdiction scorecards benchmarking real permit cycle times from open municipal
records, a project-fit checker and dynamic submission checklist driven by curated jurisdiction
playbooks, and an AI signal feed extracting planning-board actions from NJ meeting minutes.

> **Demonstration product.** Jurisdiction Intelligence OS is a portfolio project built entirely
> from public records. Benchmarks are estimates from published permit data; requirements
> summaries are curated from official sources and may be outdated. Nothing here is legal advice
> or a substitute for confirming requirements with the jurisdiction.

## Repository layout

- `OPERATING_GUIDE.md` — the canonical build manual.
- `PROGRESS.md` — session log (newest entry on top).
- `RECON.md` — Phase 0 data-source recon results, re-generated by `00_recon.py`.
- `pipeline/` — Python pipeline (recon → permit ETL → scorecards → playbooks/fit-checker →
  signal-feed extraction → delay alerts).
- `playbooks/` — `{jurisdiction}.yaml`, curated and cited jurisdiction rules.
- `eval/` — gold-set evaluation for the LLM extraction module.
- `data/` — `raw/` (gitignored), `MANIFEST.json` (source provenance).
- `web/` — Vite + React app; `public/data/` artifacts are committed (small, static, no R2/tiles
  needed — this project's data is tiny compared to the parcel-scale flood projects).

## Status

Phase 0 (bootstrap + recon) complete. Benchmark cities locked: NYC, Chicago, Austin, San
Francisco, Seattle, Los Angeles. NJ deep-dive municipalities locked: Jersey City, Hoboken,
Princeton, Montclair. See `RECON.md` for the full verification record, including four rejected
candidates and why.

## Pipeline

```bash
cd pipeline
uv sync
uv run python 00_recon.py
```

## Data sources

Open municipal permit data (Socrata) for the 6 benchmark cities; NJ municipal meeting portals
(CivicWeb/IQM2/CivicPlus/custom CMS) for the 4 deep-dive municipalities. Full source table,
exact dataset IDs, and field mappings: `RECON.md`.
